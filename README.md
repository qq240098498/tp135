# tp135 联赛赛程与积分核算台

一个本地小工具：把参赛球队、比赛场地与整季赛程登记进来，打完的场次记上比分，页面立刻算出每个积分、净胜球与名次。左侧切视图，右侧抽屉里增删改，所有数字都来自本机的数据文件，不连数据库，也不调用任何外部服务。

## 技术栈

- 后端：Node.js（>=18）与 Express，前后端同一个进程
- 前端：原生 HTML、CSS 与 JavaScript，页面由后端静态目录直接提供，没有构建步骤
- 存储：本地 JSON 文件 `data/db.json`

## 启动方式

```bash
npm install
npm start
```

启动后打开页面地址：<http://localhost:5135>

端口固定为 `5135`，如需临时改动可在启动前设置环境变量 `PORT`。

## 页面怎么用

左侧导航共六个视图：

1. 概览：球队与场地数、赛程进度、已赛与待赛场次，下面列出最近五场赛果与积分榜前三
2. 球队：按参赛状态筛选、按队名或城市搜索；点新增或编辑打开右侧抽屉填写队名、简称、城市、主场、档位、状态与备注
3. 场地：以卡片列出场地名称、城市、容量、可用日、主场球队与已排场次
4. 赛程：按轮次与状态筛选，逐场列出日期、时刻、对阵、比分、场地与状态；未打完的场次可以点登记比分，打完的场次会带上比分与胜者
5. 抽签分组：填上种子编号开抽；页面先按上赛季名次分档，再逐档抽一支落进每个组，给出分组结果、每支球队落在第几组第几档、同城回避的重试记录与落不下的球队
6. 积分榜：按名次列出场次、胜平负、进球失球、净胜与积分

任何一步不成立时，右上角弹出说明，并尽量把问题标到抽屉里对应的输入项上。

## 分组抽签口径

- 只对状态为「参赛」的球队抽签，退赛的球队单独列出、不进任何一档
- 先按上赛季名次（球队的档位字段）排序，每「组数」支球队组成一档：第 1 到第 G 名是第 1 档，第 G+1 到第 2G 名是第 2 档，依此类推；每个组从每一档恰好抽一支，所以落位完成后各组球队数必然相等
- 组数留空时自动凑：优先每组四队，其次三队、两队；参赛队数除以组数除不尽时，多出来的队凑不齐完整一档，不进抽签并单独列出原因（例如 9 队分 2 组时第 9 名落不下）
- 随机数全部由种子编号推导（编号先哈希再喂给确定性随机数发生器），不读系统时间：同一次抽签记下编号，填回同一个编号再抽，分组、落位与重试记录完全一致；换一个编号结果明显不同
- 同城回避：某支球队抽中的组里已经有同城市的球队时，这一抽作废、改投其他空组，每一次重试都写明「谁、先抽中第几组、撞上了谁、第几次重试」；当前档所有空组都撞车时退回本档重排
- 重试次数有上限（默认 500，可在页面上改成 1 到 10000）。触顶仍避不开时立即停止、绝不死循环：已抽好的部分落位保留展示，没能落位的球队逐支列出并说明；若某城市的球队多过组数（例如 2 个组却有 3 支同城球队），分档预览会提前给出预警，这种分布无论怎么抽都无解
- 抽签只在页面上算出结果，不改写赛程与数据文件；随时可以换编号重抽

抽签口径可用 `node scripts/draw-check.js` 跑断言复核（分档结构、组内人数相等、同种子复现、异种子不同、余数落不下、同城无解与退赛排除）。

## 积分与排序口径

- 只统计状态为已赛的场次，延期、取消与待赛的场次不计入
- 积分按胜一场 3 分、平一场 1 分、负一场 0 分累加，规则记在数据文件的 `meta.points` 里
- 名次依次比较：积分高的在前 → 净胜球多的在前 → 进球多的在前 → 队名排序
- 净胜球等于进球数减失球数；积分榜随每次登记比分实时重算

## 登记口径

- 球队名称不重复、最长 24 个字；简称是两到四个大写字母且不重复；档位在 1 到 12 之间且不重复；主场必须是已登记的场地；本赛季参赛球队最多 12 支
- 场地名称不重复、最长 30 个字；容量在 100 到 200000 之间；至少要选一个可用日，且同一天不能重复勾选
- 赛程的轮次在 1 到 40 之间，日期要真实存在，开赛时刻写成两位小时加两位分钟；主队与客队不能是同一支
- 同一轮里一支球队只能出场一次；同一天同一块场地两场比赛之间至少隔两小时（场地留空时按主队主场算）
- 比分只在状态为已赛时填写，取值是 0 到 99 的整数；状态不是已赛时填了比分会被拒绝
- 球队或场地被赛程引用时不能直接删除，页面会说明还有多少场挂着

## 数据存储

所有数据写在 `data/db.json`，结构为 `{ meta, teams, venues, matches }`。落盘时先写临时文件再改名替换，写入过程中断不会把数据文件写坏；文件缺失或内容损坏时回落到初始数据。初始数据里八支球队、六个场地（其中三支球队共用中立体育场，平原飞驰与沙洲锚队同属平原城，抽签时会演示同城回避）、七轮单循环二十八场，前三轮已打完，第四轮有一场延期。

## 接口一览

| 方法   | 路径                        | 说明                             |
| ------ | --------------------------- | -------------------------------- |
| GET    | /api/health                 | 服务状态检查                     |
| GET    | /api/summary                | 概览数字、最近赛果与积分榜前三   |
| GET    | /api/teams                  | 球队清单，支持状态筛选与关键词   |
| POST   | /api/teams                  | 新增球队                         |
| PATCH  | /api/teams/:id              | 修改球队                         |
| DELETE | /api/teams/:id              | 删除球队                         |
| GET    | /api/venues                 | 场地清单，支持关键词             |
| POST   | /api/venues                 | 新增场地                         |
| PATCH  | /api/venues/:id             | 修改场地                         |
| DELETE | /api/venues/:id             | 删除场地                         |
| GET    | /api/matches                | 赛程清单，支持轮次、状态与关键词 |
| POST   | /api/matches                | 新增赛程                         |
| PATCH  | /api/matches/:id            | 修改赛程                         |
| POST   | /api/matches/:id/result     | 登记比分，登记后自动标成已赛     |
| DELETE | /api/matches/:id            | 删除赛程                         |
| GET    | /api/standings              | 积分表，支持关键词               |
| GET    | /api/draw/preview           | 抽签分档预览：各档球队、落不下的队、城市无解预警 |
| POST   | /api/draw                   | 按种子编号抽签，返回分组、每队落位与重试记录 |

接口出错时统一返回 `{ "error": { "code": "...", "message": "...", "field": "..." } }`，其中 `field` 用于让页面把问题标到具体的输入项上。
